(10) the commit message carries the issue pointer as a line of its own, one line per issue the branch delivers, written exactly like this with <N> replaced by the issue number (keep `Refs`, never `Closes`):

Refs #<N>

(11) a view (its code-behind included) constructs, binds and delegates: run the host's view-domain firewall (verify-view-domain-firewall.sh, wired beside the host's rule-layer firewall in make/CI) and answer for every offence it names - a view never reads a file, opens a client, mutates application state or instantiates a domain service, because the rule lives where no host is needed to test it (ADR-0137).
